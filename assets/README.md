# Logo

| File | Use |
|---|---|
| `logo-light.svg`, `logo-dark.svg` | The logo with the name, for light and dark backgrounds |
| `icon.svg`, `icon-512.png` | The mark alone; it reads on light and dark |
| `social-preview.png` | GitHub's social preview, 1280×640 |

Don't move or rename `icon-512.png`: the footer of every GitHub comment posted with critique loads it from
`main/assets/icon-512.png`.

The lettering is [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) (SIL Open Font License 1.1),
converted to outlines. The logo is under the repo's MIT license.
